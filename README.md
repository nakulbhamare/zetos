## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm / pnpm / yarn

### Installation & Development

```bash
# Clone the repository
git clone https://github.com/nakulbhamare/zetos.git
cd zetos

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
# Type check and build production bundle
npm run build

# Preview production build
npm run preview
```
